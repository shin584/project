# 졸업 전시회 XAI 표시 방침

결정일: 2026-11-19. 사용자가 학부 졸업 전시회 용도를 설명하고, 이전 버전과
동일한 형태로 XAI 결과를 출력하며 별도의 경고는 제외하도록 요청했다.

2026-11-20 피드백에서 데스크톱 화면의 안내 문구, 설명 실행 방식, 상세보기 필터와
모델 전환 표시를 조정하기로 합의했다.

## 현재 XAI 화면 요구사항

- NT/non-NT SpCas9·Cas12a의 계산 가능한 XAI 결과는 이전 버전과 같은 그래프
  구성으로 표시한다. IG 로고, SHAP 막대·워터폴 등 기존 표현을 유지한다.
- 완결성·가법성·해상도·seed 안정성 등의 수치 품질 기준 미달만으로 그래프를
  숨기거나 경고·진단·재시도 화면으로 대체하지 않는다. 별도의 품질 경고 배너,
  팝업 또는 실패 안내는 추가하지 않는다.
- `기술적 참고`, `출력 단위 참고`, IG와 SHAP의 별도 기여도 제목과 기준 출력 안내를
  화면에서 삭제한다. 그래프 축의 단위와 대체 텍스트, 내부 보고서·로그의 품질 진단은 유지한다.
- 예측 완료와 분석 대상·기법·계산 설정 변경 시 설명을 자동 계산한다. 진행률과
  취소를 제공하며, 취소하거나 오류가 발생했을 때 `다시 계산`을 표시한다.
  기본값은 IG 32 / SHAP 64샘플·배경 4개다.
- 계산 예외·결과 없음·NaN/inf는 수치 품질 허용 오차 미달과 구별한다. 계산되지
  않은 값을 만들거나 잘못된 배열을 그래프로 표시하지 않고 기존 오류 처리를 유지한다.
- 분석 기법 선택 목록에는 NT 계열에서만 `Attention Rollout`을 표시한다.
  출력 단위 교정, Cas12a 경로·특징 일관성, 캐시 식별은 각 티켓의 기존 요구사항을 따른다.

## 관련 데스크톱 화면 요구사항

- 피드백에서 지정한 서열 입력, Best Candidates, 변종 비교, 전체 상세 보기 안내 문구와
  Best Candidates의 `모델과 출력 범위` 영역을 삭제한다. 점수 종류와 단위는 표에서 표시한다.
- 전체 상세 보기의 `최소 점수`와 `최대 거리`는 각 슬라이더 하나로 조정한다. 선택값 아래
  `0% 이상`, `15 bp 이하`와 같은 짧은 설명을 표시한다. CSV는 검색 시 적용한 조건을 사용한다.
- 모델 전환은 시작 0%, 이전 프로세스 종료 33%, 새 프로세스 시작 67%, 준비 완료 100%를 표시한다.
  퍼센트는 완료한 준비 단계의 비율이다. 자동 재분석의 진행률은 별도로 표시한다.

## 적용 및 검증

현재 표시 방침은 #191/#199/#200/#201의 과거 "실패한 설명을 정상 그래프 대신
경고·진단·재시도로 표시" 요구를 대체한다. #205 및 하위 티켓의 보고서·계약·원시
자료는 당시 수행 결과로 보존한다. 새 화면 표시를 수치 품질 통과로 기록하지 않는다.

화면 검증은 유한한 결과의 차트 표시, 설명 진행률·취소·재시도, 필터와 CSV의 일치,
모델 전환 진행률과 이전 요청 무효화를 확인한다. 기존 패키지 검증 기록은 당시 화면의
참고 문구를 기준으로 한 결과다.
