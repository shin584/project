# 졸업 전시회 XAI 표시 방침

결정일: 2026-11-19. 사용자가 학부 졸업 전시회 용도를 설명하고, 이전 버전과
동일한 형태로 XAI 결과를 출력하며 별도의 경고는 제외하도록 요청했다.

## 현재 화면 요구사항

- NT/non-NT SpCas9·Cas12a의 계산 가능한 XAI 결과는 이전 버전과 같은 그래프
  구성과 조작 방식으로 표시한다. IG 로고, SHAP 막대·워터폴 등 기존 표현을 유지한다.
- 완결성·가법성·해상도·seed 안정성 등의 수치 품질 기준 미달만으로 그래프를
  숨기거나 경고·진단·재시도 화면으로 대체하지 않는다. 별도의 품질 경고 배너,
  팝업 또는 실패 안내는 추가하지 않는다.
- 기존 기술적 참고의 수치·설명은 기존 구성대로 유지한다. 추가 품질 진단과
  검증 실패 기록은 내부 보고서·로그에 보존한다. 한계는 발표자가 구두로 설명한다.
- 정밀 계산은 사용자가 선택하는 설정 변경/재계산 기능으로 제공하고 진행률과
  취소를 유지한다. 재시도를 결과 표시의 선행 조건으로 삼거나 계산량을 자동으로
  늘리지 않는다. 기본값 IG 32 / SHAP 64샘플·배경 4개는 유지한다.
- 계산 예외·결과 없음·NaN/inf는 수치 품질 허용 오차 미달과 구별한다. 계산되지
  않은 값을 만들거나 잘못된 배열을 그래프로 표시하지 않고 기존 오류 처리를 유지한다.
- non-NT Rollout의 지원 여부, 출력 단위 교정, Cas12a 경로·특징 일관성,
  캐시 식별 및 진행률·취소 계약은 각 티켓의 기존 요구사항을 따른다.

## 적용 및 검증

현재 표시 방침은 #191/#199/#200/#201의 과거 "실패한 설명을 정상 그래프 대신
경고·진단·재시도로 표시" 요구를 대체한다. #205 및 하위 티켓의 보고서·계약·원시
자료는 당시 수행 결과로 보존한다. 새 화면 표시를 수치 품질 통과로 기록하지 않는다.

후속 화면 구현에서는 유한한 결과가 품질 허용 오차를 넘더라도 기존 차트가 표시되고
별도 경고가 추가되지 않는지, 선택 정밀 계산의 진행률·취소가 동작하는지 확인한다.
실제 수치 검증 결과는 별도로 기록한다.

이번 변경은 요구사항 정정이며 #199/#200/#201의 모델 연결·화면 구현 완료를 뜻하지 않는다.
