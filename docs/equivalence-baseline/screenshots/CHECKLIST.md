# 스크린샷 체크리스트 (#181 동등성 기준)

게이트 2는 데스크톱 화면을 이 그림들과 항목별로 대조한다. 자동으로 찍으려면
`python docs/equivalence-baseline/shoot_screenshots.py`, 손으로 찍으려면 아래 항목이
한 장 안에 모두 보이도록 찍는다. 파일 이름은 그대로 쓴다.

입력은 `capture_baseline.py`의 `FIXED_INPUT` 하나다 (81bp, NGG·TTTV 둘 다 포함).
브라우저 폭은 1600px, 사이드바를 펼친 상태, 전체 페이지(full page)로 찍는다.

## 공통 (모든 장에 보여야 한다)

- [ ] 사이드바: "서열 입력" 제목, 81bp 입력칸, **분석 시작** 버튼
- [ ] 사이드바: **XAI 그래프 크기** 슬라이더 (40~100%, 기본 80%)
- [ ] 상단: 제목 "CRISPR PAM Scanner + XAI"와 설명 한 줄
- [ ] "PAM 탐색 결과" 아래 Cas별 발견 개수 metric 2개
- [ ] "절단 효율 예측 결과" 캡션 (Cas12a=효율, SpCas9=백분위 설명)
- [ ] "모델 출력 해석 상태" 펼침 블록 (접힌 상태로도 제목이 보여야 한다)
- [ ] 보기 전환 라디오 4개가 가로로

### 덮이지 않는 분기

현재 두 Cas 모두 `score_kind="efficiency"`라 점수 단위가 섞이지 않는다. 그래서
`app.py`가 **Cas별로 표를 나누는 가지**(`#### <Cas> · N개 사이트` 제목, "서로 다른 표의
숫자는 직접 비교할 수 없습니다" 캡션, 백분위 캡션)는 이 입력으로 실행되지 않는다.
`MODEL_REGISTRY`에서 SpCas9이 다시 백분위로 돌아가면 이 기준을 다시 떠야 한다.

## 재계산이 일어나지 않는지 (그림이 아니라 동작)

스크린샷으로는 안 보이지만 같은 기준에 포함한다. 데스크톱에서 확인할 것:

- [ ] 보기를 전환해도 예측을 다시 하지 않는다
- [ ] XAI 그래프 크기 슬라이더만 움직이면 XAI를 다시 계산하지 않는다
      (Streamlit은 `show_figure()`가 `session_state`에서 읽어 재계산하지 않는다)
- [ ] 같은 사이트·같은 설정으로 기법을 오갔다가 돌아오면 다시 계산하지 않는다
