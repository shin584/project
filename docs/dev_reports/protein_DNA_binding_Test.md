# 단백질-DNA 결합 확인 테스트
## 실제로 모델이 단백질과 DNA의 결합을 시뮬레이션 하는지 확인

* 일부 도메인 서열이 아닌 전체 서열을 chai-1 서버에서 시뮬레이션
* 이후 결과 파일을 분석
```text
============================================================
Chai-1 3D Feature Comparison: Positive vs Negative
============================================================
Feature (피처)                   | Positive (GGG)  | Negative (TTC)  | Variance (격차)
---------------------------------------------------------------------------------
Overall ipTM (전체 신뢰도)          | 0.8347          | 0.8359          | -0.0011
Cas9-DNA(T) Pair ipTM          | 0.0715          | 0.0668          | +0.0048
Cas9-DNA(NT) Pair ipTM         | 0.0571          | 0.0652          | -0.0081
Mean PAE (Cas9-DNA 위치 오차)      | 21.35           | 20.83           | +-0.52 (Error ↑)
================================================================================
pair iptm이 0에 수렴함. 결합을 전혀 구현 못하고 있음을 의미.
전체 신뢰도가 높은 이유는 단백질과 dna 각각은 정확하게 구현하고 있기 때문으로 생각됨.
============================================================
```

* AlphaFold 3에서 시뮬레이션한 결과 요약
```text
============================================================
1. 전체 복합체 결합 신뢰도 (ipTM) : 0.9000 (0.8 이상이면 우수)
2. 전체 단백질 접힘 신뢰도 (pTM)  : 0.8900
------------------------------------------------------------
3. Cas9(단백질) - Target DNA(타겟) 결합력  : 0.9100
4. Cas9(단백질) - Non-Target DNA 결합력 : 0.9300
-------------------------------------------------------------
```
* 단백질과 dna가 결합한 모습을 볼 수 있음.
