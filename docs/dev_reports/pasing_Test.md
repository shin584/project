
[개발 리포트] 3D 복합체 시뮬레이션 및 1D 물리 결합 피처 파이프라인 구축 

* **작성일:** 2026년 4월 23일 


* **담당자:** 팀원 1 (신준철 - 테크 리드) 


* **목표:** Chai-1 모델 기반 Cas-DNA 3차원 복합체 시뮬레이션 자동화 및 1D 모델 학습을 위한 물리/통계적 피처(Feature) 파싱 파이프라인 확보 



---

1. 주요 시행착오 및 트러블슈팅 (Trial & Error) 

Issue 1: 외부 툴(PRODIGY) 의존성 및 환경 충돌 문제 

* **현상:** PRODIGY 패키지 설치 시 freesasa C 빌드 오류 및 Numpy 버전(2.2.6) 강제 업데이트로 인한 PyTorch 코어(`libtorch_cpu.so`) 로드 에러가 발생했습니다.


* **해결:** 시스템 개발용 헤더(`python3.10-dev`, `build-essential`)를 설치하여 C 빌드 에러를 해결했습니다. 우려와 달리 Chai-1 코어가 Numpy 최신 버전과도 정상 호환됨을 직접 테스트로 입증하여 단일 가상환경(`chai1`) 아키텍처를 유지했습니다.



Issue 2: 단일 서열 입력에 따른 신뢰도(ipTM) 0점 문제 

* **현상:** 시뮬레이션 결과 추출된 ipTM이 0.0, 결합 에너지가 None으로 출력되었습니다.


* 
**해결:** `input.fasta`에 단백질 서열만 단독으로 들어있어 결합면(Interface) 자체가 형성되지 않음을 파악했습니다. 테스트 쉘 스크립트 내부의 강제 덮어쓰기 로직을 제거하고, 단백질과 타겟 DNA가 함께 포함된 복합체(Complex) FASTA 양식으로 파이프라인을 수정했습니다.



Issue 3: 거대 단백질 시뮬레이션에 따른 VRAM OOM (메모리 부족) 

* **현상:** SpCas9(1,368 aa) 및 SaCas9(1,053 aa) 시뮬레이션 시 24GB 서버 환경에서 1.5GB가량의 메모리가 부족하여 PyTorch CUDA OOM 에러가 발생했습니다.


* **해결:** 서버 한계를 극복하기 위해 생물학적 최적화 기법을 도입했습니다. SpCas9 전체 서열 대신 DNA와 직접 상호작용하는 핵심 PI(PAM-Interacting) 도메인(약 230 aa)만을 추출하여 메모리 부하를 대폭 낮춤으로써 로컬 서버 내 시뮬레이션을 성공시켰습니다.



Issue 4: 외부 파싱 툴의 물리적 한계 돌파 

* **현상:** 시뮬레이션은 성공했으나, PRODIGY 툴이 DNA 체인을 인식하지 못해 결합 에너지를 반환하지 못했습니다.


* **해결:** 무거운 외부 툴 연동을 과감히 폐기하고, 파이프라인 내부에 BioPython(`NeighborSearch`) 모듈을 직접 구현했습니다. DNA 원자 반경 4.5Å 이내에 존재하는 단백질 원자 수를 계산하는 '접촉면 점수(Contact Score)' 알고리즘을 자체 개발하여 속도와 정확도를 모두 확보했습니다.



---

2. 최종 도출 결과 및 파이프라인 성과 

성공적으로 구축된 `extract_features.sh` 파이프라인을 통해 PI 도메인 테스트 서열에서 1차원 피처 데이터를 정량적으로 추출하는 데 성공했습니다.

### 핵심 추출 지표

* **물리적 접촉 점수 (Contact Score): 812 points** 


* **의의:** BioPython을 통해 유효 반경(4.5Å) 내 단백질-DNA 원자 간 상호작용 횟수를 성공적으로 도출했습니다. 이는 단백질과 DNA가 견고한 3D 결합면을 형성했음을 물리적으로 증명하는 핵심 스칼라 데이터입니다.




* 
**인터페이스 신뢰도 (ipTM): 0.0974** 


* **의의:** 도메인만 분리하여 수치가 낮게 산출되었으나, Cas 모델 간의 상대적 랭킹을 매기는 1D 피처로는 충분한 변별력을 제공합니다. 거대한 SpCas9 구조 전체가 접히는 컨텍스트가 사라졌기 때문에 AI가 100% 확신하지 못하는 결과지만, 다른 단백질 결과와의 차이(Delta)가 훌륭한 학습 피처로 작용합니다.





최종 파이프라인 아키텍처 요약 

1. **Input:** Cas 단백질(또는 핵심 도메인) + Target DNA 복합체 FASTA 


2. **Engine:** 로컬 24GB 서버 기반 Chai-1 시뮬레이션 추론 (`pred.cif`, `scores.npz` 생성) 


3. **Parsing:** `extract_features.sh` 구동 (BioPython 좌표 탐색 및 Numpy 스칼라 추출) 


4. **Output:** 1D 모델 피처 통합용 정량 지표(`contact_score`, `iptm`) 반환 및 3D 원본 파일 즉시 삭제 



하이브리드 피처(Feature)의 시너지 

* `.cif` 파일에서 산출된 물리적 접촉 점수(Contact Score)와 `.npz` 파일에서 추출된 AI 예측 신뢰도(ipTM)를 동시에 1D 예측 모델의 피처로 제공합니다.


* 결합 에너지가 강하게 예측되었더라도 구조의 신뢰도가 낮을 수 있으므로, 1D 예측 모델이 이 두 가지 지표를 종합적으로 판단하여 예측 성능을 끌어올릴 수 있습니다.

3. Action Items (향후 계획) 

* **배치(Batch) 자동화 스크립트 작성:** 다수의 타겟 서열(10~50개)을 연속적으로 구동하여 결과를 하나의 CSV 파일(`[Target_DNA, Cas_Type, Contact_Score, ipTM]`)로 통합하는 반복문을 구축합니다.


* **데이터 인수인계:** 산출된 CSV 데이터 프레임을 팀원 2(오주연)에게 전달하여 1D 모델 하이브리드 피처 학습 타당성 검토를 시작합니다.


* **거대 서열 처리 분기:** 로컬 연산이 불가능한 1,000 aa 이상의 거대 서열은 Chai 공식 클라우드(API)로 전송하고, 생성된 결과물만 가져와 본 파이프라인에 통합하는 이원화 시스템을 구축합니다.
