# #203 첫 실행 — 측정 도구 검사 오류로 중단

실행 전 `contract.json`을 등록하고 기존 NT 소스를 실행했다. SpCas9 IG와 SHAP
표시는 확인했으나, Rollout의 정상 그래프 수 2개를 1개로 잘못 검사해 중단했다.
창 검사는 **2 통과 / 1 실패 / 0 건너뜀**이며 Cas12a와 v3 단계는 실행하지 못했다.
이 결과를 전체 RAM 비교나 앱의 Rollout 실패로 사용하지 않는다.

`legacy/`에 실제 로그·원시 측정·검사 결과를 보존한다. 1,370회 sample, 접근 오류와
종료 후 잔여 프로세스는 0개였다. `observer/`는 당시 사용한 측정 코드의 원본이다.
이 폴더의 코드 중복은 실패 실행을 재현하기 위한 보관이며 현재 실행 도구는 상위
`docs/benchmarks/`의 파일이다. 검사 수정과 계산/디스크 캐시 관찰을 추가한 뒤
별도 `issue203-ram-20261119-run02`에 다시 등록했다.
