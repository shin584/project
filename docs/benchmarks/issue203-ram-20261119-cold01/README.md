# #203 기존 NT의 SHAP 새 계산 추가 실험

기본 비교에서 기존 프로그램의 두 SHAP이 디스크 캐시에 적중한 것을 확인한 뒤,
lookup만 미적중으로 돌리는 조건을 `contract.json`에 별도로 등록했다. 모델·입력·
IG32·SHAP64/4·렌더링·캐시 보유 정책은 그대로다. 원본 파일은 변경하지 않았다.

두 SHAP을 실제 계산했고 디스크 적중은 0회다. 창 검사 **6 통과 / 0 실패 / 0 건너뜀**,
exit 0, 종료 후 잔여 프로세스 0개다. 2,669회 원시 sample을 보존했다.
[단계별 요약](summary.json)과 [전체 결과](../../issue203-implementation.md)를 참조한다.
v3 실행은 이 추가 계약의 계획 대상이 아니며 기본 비교의 독립 v3 실측을 사용한다.
