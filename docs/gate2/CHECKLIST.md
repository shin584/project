## #189 배치와 진행률 재확인

기존 위쪽의 공통 결과 영역을 Best Candidates 안으로 옮긴 것은 #189에서 합의한
배치 변경이다. 모델 예측 진행률도 기존 제목 아래의 작업 영역에서 표시한다.
sticky/fixed 영역은 추가하지 않았다. 후보 사이트 표와 모델 출력 해석 상태는
기존 details 펼침 동작을 유지한다.

기본 1280×840 실제 창과 실제 모델로 확인한 화면·진행 이벤트·가시 영역은
[추가 검증 기록](issue189/README.md)에 있다. 이번 기록은 소스 실행에 대한 것으로,
위 표의 #188 exe 증거 및 다른 PC 미확인 판정을 대체하지 않는다.
