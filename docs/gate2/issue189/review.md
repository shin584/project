## Standards

최종 지적 0건. 작업 위치·브랜치·로컬 통합본 규칙을 유지한다. 공개 함수·슬롯·
이벤트 계약을 변경하지 않고, 기존 숫자 진행률을 화면에서 표현한다.
입력 구간 HTML은 기존 Renderer가 생성하며 화면은 노드를 옮긴다.
사이트 키로 이전 구간의 유지·제거 여부를 판단한다.

## Spec

초기 지적 1건: 모델 입력 구간이 계산 설정 아래에 남아 있어 합의한 XAI 표시
순서와 달랐다. 해당 구간을 대상 선택 다음, 점수 요약·설정 위로 옮겼다.
같은 사이트의 재계산에서는 유지하고 새 사이트·새 분석에서는 지운다.
재검토 지적 0건. 첫 설명 완료 전부터 입력 구간이 있어야 한다는 요구는 없으므로
기존 결과 생성 시점을 유지한다.

Best Candidates 한정 표시, 기존 상단 진행률, 두 모델의 done/total 표시와
완료·취소·오류 정리, 요청 ID 검사, 탭 전환 시 계산 유지에 추가 지적은 없다.
