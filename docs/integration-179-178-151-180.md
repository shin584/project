## 합친 내용

- 코어와 Streamlit 화면은 현재 폴더 루트의 `predict.py`, `pam_scanner.py`,
  `model_source.py`, `app.py`, `xai/`에 있다.
- `predict.py`는 #151의 `functools.cache`·로드 로그, #179의 오프라인 로더,
  #180의 선택 `on_batch` 콜백을 모두 포함한다.
- #151이 제거한 `final_score`를 가짜 구현도 전달하지 않도록 맞췄다.
  #178의 승인된 함수·이벤트·슬롯 계약은 유지한다.
- `desktop/fake.py`, `packaging/prepare.py`, `packaging/gate1.spec`는 현재
  폴더의 코어와 모델을 사용한다. 형제 체크아웃 경로는 필요하지 않다.
- `models/Cas12a.safetensors`, `models/SpCas9.safetensors`는 원본 가중치의
  독립 사본이다. 두 파일은 Git에서 무시한다.
- `data/`에는 Model B의 사전계산 결과·메타데이터와 SHAP 캐시 두 개를
  복사했다. 필요한 CSV는 상위 `.gitignore`에 의해 누락되지 않도록 예외를 뒀다.
- `test/`의 코어 테스트와 `tests/`의 Streamlit·취소·데스크톱 테스트를 합쳤다.
  가짜 구현의 의존성 검사는 새 프로세스에서 수행해 테스트 실행 순서에
  영향받지 않도록 했다.

## 검증

```powershell
python -X utf8 -m pytest test tests -q
python -m ruff check desktop packaging tests/test_desktop_api.py tests/test_integrated_layout.py
```

통합 테스트 **121개 통과**. 기존 SHAP 특이행렬 경고 1건이 있다.
Ruff 검사도 통과했다. 형제 저장소가 없는 임시 폴더에 코드를 복사한 테스트에서
코어 import·가짜 예측이 성공했고, 패키징 모드의 토크나이저 캐싱과
누락 리소스의 네트워크 우회 방지도 확인했다.

테스트 원문은 `.packaging/evidence/integration-tests.xml`에 있다.
가중치 두 개는 SHA-256이 원본과 일치하며, 복사한 `data/` 파일도 원본과
바이트 단위로 일치한다. 원본 Streamlit 화면 두 파일은 수정하지 않았다.

## 패키징 재검증

현재 폴더의 소스로 PyInstaller 빌드를 다시 만들었다. 빌드 안의 코드도
검사해 `predict`, `pam_scanner`, `model_source`, `xai.explain`이 모두 현재
폴더에서 수집됐고, 캐시·오프라인 로딩·취소 콜백이 함께 들어갔음을 확인했다.

새 EXE를 빈 작업 폴더에서 Windows 디렉터리만 포함한 PATH로 실행했다.
각 실행에서 HF 캐시를 새로 만들고 Python 네트워크 연결을 차단하는
기존 #179 검증 방식을 사용했다. **종료 코드 0, 개발 PC 검증 통과**.

- Cas12a 예측 1개, SpCas9 예측 8개(WT 포함).
- SHAP 캐시 미적중 계산(8 samples / 배경 1개, 추론 콜백 3회),
  IG 2단계, Rollout 24층.
- WebView에서 matplotlib PNG data URI 표시 성공.
- TCP 리스너·Python 네트워크 시도·감시 오류 모두 0건.
- 입력·예측 개수·기록된 SHAP/IG 수치·Rollout 층수가 원래 #179 검증과 일치.
- 배포 폴더는 6,846개 파일, 5,472,844,161 bytes. 검증된 새 빌드는
  `dist/XaiGate1`, 이전 빌드는 `.packaging/pre-integration-dist/XaiGate1`에 있다.

커밋·모델 해시·소스 해시·EXE 해시·실행 결과 전체는
[검증 JSON](benchmarks/desktop-integration-2026-11-16.json)에 남겼다.
원문 로그는 `.packaging/evidence/integration-build.log`,
`.packaging/evidence/integration-exe-result.json`에 있다.

## 범위

현재 구현에는 호출 경계와 가짜 Renderer가 있다. 실제 Renderer·완성된
데스크톱 화면은 후속 티켓에서 연결한다. 기존 Streamlit 화면은
`python -m streamlit run app.py`로 현재 폴더에서 실행한다.

#179의 깨끗한 Windows 오프라인 환경 통과 판정은 여전히 별도 검증이 필요하다.
개발 PC에서의 테스트·빌드·실행 성공은 그 판정을 대신하지 않는다.
