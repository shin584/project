# #204 배포 빌드 디스크 예산

#192의 보존본과 기존 NT 실행 폴더는 유지한다. #193의 런타임 추정에 새 배포의
wheelhouse, 격리된 venv, 입력 staging, PyInstaller 산출물과 독립 실행용 복사본을
추가한다. 모두 C:의 새 경로에 만든다. 2026-11-19 입력 획득 후 C: 여유 공간은
36,085,133,312바이트였다.

| 추가 점유 항목 | 예산 (GB, 10⁹ 바이트) |
| --- | ---: |
| 로컬 wheelhouse, 이미 확보 | 1 |
| 신규 빌드 venv | 3 |
| 체크섬 검증 후 복구한 모델·토크나이저·WebView2 staging | 4.6 |
| PyInstaller 분석·작업 폴더·캐시 | 4 |
| 새 배포 폴더 | 7 |
| 개발 폴더와 분리한 실행용 복사본 | 7 |
| 측정 로그 및 여유 | 5.4 |
| 합계 | 32 |

격리된 Windows 게스트에서 실행하는 경우 게스트 내부에 추가 복사본을 만들 수
있으므로 게스트 디스크 공간을 별도로 확인한다.
